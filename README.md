# المحاسبة من الصفر

أكاديمية تفاعلية بالعربي (عامية مصرية) لتعلم أساسيات المحاسبة، جزء من منصة أكاديميات Infinity University Activity.

**الموقع المباشر:** https://capwv.github.io/accounting-from-zero/

## المحتوى

- **14 درس**
- **84 سؤال تفاعلي** بتصحيح فوري وشرح
- **56 تمرين** بحل نموذجي
- **معمل** جوه المتصفح: حاسبات (معادلة محاسبية، ربح، إهلاك، ضريبة), تحديات حسابية، "مدين ولا دائن؟"

كل الأمثلة من "مكتبة سلمى" الوهمية، وكل الأرقام محسوبة ومتوازنة. المحتوى تعليمي وليس نصيحة ضريبية أو قانونية.
